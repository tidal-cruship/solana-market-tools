Open-source tools for Solana blockchain research.

- Market trend analysis
- Wallet activity research
- Paper trading simulations
- Risk management tools

## Disclaimer

## How to Run

Requirements: Python 3

1. Clone this repository.
2. Open the project folder.
3. Run:

python wallet_tracker_demo.py

4. Enter a public Solana wallet address.
